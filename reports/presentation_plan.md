# Презентация PDF — спека (п.1.8 Положения дословно, из review A13)

Источник требований: polozhenie.pdf п.1.8 — презентация обязана содержать:
1. **архитектура решения** (схема пайплайна)
2. **сравнение моделей прогнозирования** (таблица/фигуры с Prophet)
3. **сравнение методов детекции** (фронтир, матрица)
4. **метрики качества** (MAE обязательна)
5. **интерпретация на реальных примерах** (поимённые МО)

Формат: PDF, русский, ≤ 12 слайдов, читается без нас. Шрифт с кириллицей. Каждый слайд = заголовок-вывод.

## План слайдов (черновик, числа подставляются из outputs после make tables)

1. **Титул**: задача, данные, одна строка результата (champion + RelMAE + победа над Prophet).
2. **Данные и задача** (панель 2016×24×6, руб/жителя; карта-мини).
3. **Архитектура решения** (одна диаграмма: данные → таргет log1p → валидация expanding origins → модели → CPD → новости → выводы). П.1.8-1.
4. **Сравнение моделей** (фигура F5: распределение RelMAE + таблица чемпионов по горизонтам; Prophet A/B/B* — три строки, знание 730-дневного порога). П.1.8-2.
5. **Foundation-модели**: Chronos-2 + TimesFM 2.5, честная карта «где выигрывают/проигрывают», стоимость (минуты vs часы), лицензионная таблица отклонённых.
6. **Метрики**: MAE по горизонтам (контракт), median nMAE, RelMAE, win rate; почему нет sMAPE/MAPE (одна строка с цитатами). П.1.8-3/4.
7. **Детекция**: фронтир F1×FAR (фигура), рабочая точка из бюджета ложных тревог, витрина рядов F3 (Богородский/Дальнереченский/Якутия-контроль/штиль-контроль). П.1.8-3.
8. **Раннее выявление — честный ноль**: «предупреждения на месячной панели не существует» + протокол, который это доказал (радар, пространственное распространение, refit) — подача как результат.
9. **Новости**: механизм (словарь κ=0.926, темы→каналы→нагрузки), честный ноль по прогнозу (Holm), живой тест burst×CPD (содержательные совпадения окт-2024/май-2024).
10. **Интерпретация на реальных примерах** (п.1.8-5): 2–3 карточки МО с числами (маркетплейс-волна Богородский +402% навсегда; сезонность Севера как ложный друг; номинал vs реал: +15.1% номинал = +5–6% реал, совпадает с еженедельниками лаборатории).
11. **Ограничения и воспроизводимость**: 24 мес, 1 фолд h=12, make reproduce, MANIFEST/decision.json, 5 сидов LGBM.
12. **Что бы мы делали с 36 месяцами данных** (future work, 3 пункта — честно и амбициозно).
