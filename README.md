# Прогнозирование потребления и раннее выявление шоков в муниципалитетах России

Решение задачи направления «Прогнозирование» онлайн-конкурса СберИндекса 2026.

**TL;DR.** Панель 2 016 МО × 24 мес × 6 категорий (руб/жителя/мес). Полный ростер из 17
конфигураций моделей (статистика, Prophet A/B/B*, глобальный LightGBM, foundation
zero-shot Chronos-2 и TimesFM 2.5) на замороженной rolling-origin сетке (origins 12..23,
горизонты 1/3/6/12, только matched cells). Детекция структурных изменений — фронтир
F1×FAR с калибровкой порогов по бюджету ложных тревог. Новостной слой (27 806 заголовков,
типизированный словарь, κ=0.926) — и в прогнозе, и в детекции. Главные честные
результаты — отрицательные и доказанные: забегающего предупреждения на месячной
панели не существует; новостной прирост на h≥1 статистически неотличим от нуля
(паттерн Kalamara et al. 2022).

## Воспроизведение

```bash
git clone <repo> && cd repo-forecast
python3.12 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
make reproduce   # данные → панель → все прогоны → таблицы (CPU, ~6–8 ч на 8 ядрах)
```

| Число в отчёте | Команда |
|---|---|
| Таблица T1 (модель × горизонт, matched cells) | `make tables` → `outputs/T1_model_x_horizon.csv` |
| Значимость (DM/Wilcoxon/Holm, bootstrap) | `make tables` → `outputs/T3_significance.csv` |
| CPD-фронтир | `make cpd` → `outputs/cpd_frontier_v2.csv` |
| Новости-абляция со статистикой | `make news` → `outputs/news_ablation_*.csv` |

Целостность входных данных: `configs/MANIFEST.sha256`. Реестр решений и предрегистрация:
`configs/validation.yaml`, `configs/champion.yaml`, `configs/news_taxonomy.yaml`,
`configs/decision.json` (с журналом аудита rc0 от 06.10).

## Данные

Используются наборы данных Лаборатории СберИндекс (лицензия CC BY-SA 4.0, атрибуция:
Лаборатория СберИндекс, sberindex.ru): потребительские безналичные расходы на уровне
муниципальных образований (2023–2024), индекс доступности рынков, автодорожные расстояния,
справочник муниципальных образований. Сырые данные в репозиторий не включены; загрузка:
`make data` (скачивание с официальных URL + проверка sha256). Новостный корпус —
заголовки «Коммерсанта» и «Ведомостей» 2023–2024 (факты и даты публикаций, не объект
авторского права), сборка — `scripts/crawl_news_headlines.py` (в корне проекта).

## Структура

- `configs/` — замороженные до прогонов конфигурации (pre-registration) + журнал решений
- `src/` — панель, валидация, метрики, статистика значимости
- `scripts/` — шаги пайплайна (нумерованы в порядке выполнения)
- `reports/` — методологический отчёт (methodology.md) и презентация
- `outputs/` — результаты прогонов (не версионируются, воспроизводятся `make reproduce`)
- `tests/` — тесты целостности (утечки, matched cells, схемы)
