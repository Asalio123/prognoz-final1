# Прогнозирование потребления и раннее выявление шоков в муниципалитетах России

**Результат одной строкой: на категории «Все категории» наш DriftAdjSNaive на горизонте h=1 даёт RelMAE 0.324 против 0.460 у сильнейшей честной конфигурации Prophet-B* (−34%, парный Wilcoxon по 2 016 рядам, p=1.4e-241 с поправкой Holm) — и мы же измерением подтверждаем преимущество Prophet-B* на полном пуле шести категорий (оба прочтения критерия К2 закрыты).**

Решение направления «Прогнозирование» онлайн-конкурса СберИндекса 2026.
Презентация для жюри: `reports/presentation.pdf`. Методологический отчёт: `reports/methodology.md`.

## TL;DR для жюри

- **Панель:** 2 016 МО × 24 мес (2023-01–2024-12) × 6 категорий трат, руб/жителя/мес. Валидация — expanding rolling-origin, заморожена до прогонов (`configs/validation.yaml`, коммит e3aa46e от 04.10.2026); все ячейки всех таблиц — строго matched (пересечение ряд × origin × шаг).
- **Прогноз (К2):** 20 конфигураций в 5 слоях (статистика, Prophet A/B/B*, глобальный LightGBM, zero-shot Chronos-2 и TimesFM 2.5). Победа засчитывается против Prophet-B* — версии с корректно включённой yearly-сезонностью (порог 730 дней в исходнике Prophet документируем как ловушку, а не используем). Чемпионы: DriftAdjSNaive (h=1/3/6), SeasProfileHA (h=12) — без обучения, считаются минуты.
- **Детекция (К3):** сравнение по фронтиру F1×FAR с бюджетом ложных тревог, disjoint калибровка/измерение. Честный итог: при строгом бюджете (FAR ≤ 2/1000 МО-мес) мощность всех методов мала (лучший BOCPD, recall 5.6%) — это цена бюджета, а не слабость метода.
- **Главный отрицательный результат (измерен):** забегающего предупреждения шоков на месячной панели не существует — проверены и отвергнуты пространственное распространение (42 404 соседские пары, лифт ≈1.0, p>0.5), панельный радар (PR-AUC 0.049 против базы 0.048) и refit-от-брейка (ΔMAE +1.1% — хуже). Работает быстрая детекция (0–1 мес) и ранняя интерпретация через новости.
- **Продуктовый артефакт:** форвардный прогноз на 2025-H1 по всем 2 016 МО; честная проверка на национальном агрегате против официального ряда Лаборатории — прогноз +13.3% г/г, MAE 1.48 п.п., официальные значения внутри 80%-полосы в 6/6 месяцах (`outputs/forecast_2025H1.parquet`).

## Quickstart

```bash
git clone <url репозитория> && cd repo-forecast
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

make data        # скачивание с официальных URL + проверка sha256 (~минуты)
make reproduce   # полный контур: данные → панель → все прогоны → таблицы → фигуры → тесты
```

Честное время: `make reproduce` — **~9–11 ч wall на 8 ядрах CPU** (доминируют стат-сетка ~2.6 ч и Prophet ~4.5–5 ч; TimesFM ~3 ч CPU можно закомментировать в таргете `reproduce`).

Быстрый контур (~10–15 мин, без полного прогона):

```bash
make smoke   # данные → чистая панель → тесты целостности
```

Отдельные числа отчёта воспроизводятся точечно:

| Число в отчёте | Команда |
|---|---|
| Таблица T1 (модель × горизонт, matched cells) | `make tables` → `outputs/T1_model_x_horizon.csv` |
| Значимость (DM/Wilcoxon/Holm, bootstrap) | `make tables` → `outputs/T3_significance.csv` |
| CPD-фронтир | `make cpd` → `outputs/cpd_frontier_v2.csv` |
| Новости-абляция со статистикой | `make news` → `outputs/news_ablation_*.csv` |

## Честные ограничения

- 24 месяца = один полный годовой цикл в train максимум; h=12 — ровно один origin: временная обобщаемость ограничена единственным переходом «2023→2024» (статистическая мощность на h=12 — только кросс-секцией из 2 016 парных ошибок).
- Данные 2023–2024; прогноз на 2025 — экстраполяция, проверяемая только на национальном агрегате (на уровне МО валидации не существует — данных 2025 нет); категорийный провал форварда на Общепите показан в отчёте явно.
- Забегающего предупреждения шоков на месячной сетке нет (измерено, §4 отчёта): детектор — инструмент мониторинга и интерпретации с задержкой 0–1 мес, не предсказания.
