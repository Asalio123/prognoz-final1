## 1. Краткое резюме исследования (Executive Summary)

### Задача
Прогнозирование безналичных расходов населения по **2 016 муниципальным образованиям** (МО) России в 6 категориях трат на горизонты от 1 до 12 месяцев по 24-месячной панели СберИндекса (2023–2024), построение калиброванных интервалов неопределенности и оперативное обнаружение структурных экономических шоков.

### Архитектурное решение: Двухконтурная система
На коротких временных рядах (24 месяца) попытка решать обе задачи одной моделью приводит к деградации: брейк-поинты ломают базовый прогноз, а сложные нейросети переобучаются на локальных всплесках. Мы разделили систему на два независимых контура:
1. **Контур А (Базовый прогноз и риск-коридоры):** робастная адаптивная статистика с поправкой на панельный тренд (`DriftAdjSNaive`) + конформные интервалы (`Mondrian split-conformal`).
2. **Контур Б (Мониторинг аномалий и контекст):** байесовская детекция структурных сдвигов (`BOCPD`) с жестким лимитом ложных тревог + смысловая атрибуция по потоку 27 806 новостей деловых медиа.

## 2. Ключевые результаты в цифрах

### 1. Точность прогноза в рублях (К2, К6)
- **Сводная категория «Все категории» (h=1):** наш чемпион `DriftAdjSNaive` достигает MAE **1 322 ₽ / чел.** против **1 877 ₽** у `Prophet-B*` (−555 ₽, −34% ошибки; RelMAE 0.324 vs 0.460). Преимущество подтверждено на всех горизонтах: h=1 (−34%), h=3 (−8%), h=6 (−11%), h=12 (−22%).
- **Полный пул 6 категорий:** `Prophet-B*` лидирует по pooled MAE (597 ₽ против 635 ₽ на h=1) — преимущество Prophet на пуле строго подтверждено измерением в соответствии с рамкой §6.2 Положения конкурса.
- **Отраслевые чемпионы:** на Маркетплейсах (h=1) выигрывает `LightGBM+news` (RelMAE 0.281 / 468 ₽), на Здоровье (h=1/6) — `TimesFM 2.5` (93 ₽ / 123 ₽). Полная матрица зафиксирована в `outputs/headline/t5_category_champions.csv`.

### 2. Калиброванные интервалы риска (К6)
- **Конформное покрытие (80% PI):** 87.5% (h=1), 91.4% (h=3), 93.7% (h=6) при номинале 80%.
- **Mondrian-калибровка:** ликвидировала систематическое недопокрытие в малых МО (рост с 0.734 до 0.833) без раздувания ширины доверительного интервала.
- **Календарь рисков:** в декабре система автоматически расширяет коридоры неопределенности для 82.6% территорий под сезонный новогодний пик.

### 3. Детекция структурных сдвигов (К3)
- **Жесткий бюджет ложных тревог:** при нормативе FAR ≤ 2/1000 МО-мес (~4 сигнала в месяц на всю страну) алгоритм `BOCPD` показывает F1 = 0.67 против 0.40 у классического PELT.
- **Фильтрация ложной сезонности:** сезонная декомпозиция дала 0.0% ложных тревог на резких декабрьских пиках (против 64% у наивной нормировки).
- ** डाउनстрим-эффект:** сброс окна обучения после брейка (refit) не улучшает числовой прогноз (ΔMAE +1.1%): задача детектора — оперативный мониторинг и объяснение, а не переобучение.

### 4. Границы опережающих сигналов (К3, К7)
- **Пространственный перенос:** лифт у соседних МО (≤80 км) равен 1.08 (p = 0.77, 42 404 пары) — потребительские шоки строго локальны и не распространяются пространственной волной.
- **Панельный радар:** заблаговременный прогноз за 30 дней дает PR-AUC 0.049 при фоне 0.048 — опережающего сигнала на месячной сетке нет.
- **Рабочая точка:** практическая ценность детектора заключается в быстрой фиксации аномалий с лагом 0–1 месяц, что **опережает официальные публикации Росстата на 1–2 месяца**.

### 5. Новостной анализ (К5)
- **Таксономия и надежность:** 6 макро-тем, мультилейбл-словарь с коэффициентом согласия Коэна $\kappa = 0.926$ с ручной экспертной разметкой (активные темы 0.85–1.00).
- **Разделение функций:** включение новостей в числовой прогноз увеличивает ошибку (+11…+21% к MAE из-за макро-шума на коротких рядах). Однако в контуре детекции матрица всплесков надёжно отделяет общенациональные шоки от изолированных локальных сдвигов.
- **Временно́е плацебо:** рандомизация дат новостей дает p = 0.84, подтверждая, что тексты служат инструментом смысловой интерпретации, а не числовым предиктором.

### 6. Продуктовый форвард на 2025-H1 (К1, К2)
- **Сверка с официальным рядом:** средний форвардный прогноз составляет +13.3% г/г против факта +14.5% (смещение −1.2 п.п. — базовый тренд без новых макро-шоков).
- **Точность:** MAE форварда — **1.48 п.п.** против официального ряда СберИндекса (наивный бенчмарк повторения 2024 года дает 2.94 п.п. $\to$ **мы в 2.0× точнее**).
- **Надежность:** официальный факт удержан внутри 80%-полосы неопределенности во всех 6 месяцах из 6 (100%).
- **Методологическая честность:** полугодие H2 ответственно не публикуется, так как бэктест-чемпион горизонта h=12 провалил форвард-контроль (MAE 28.0 п.п. на январе).

## 4. Быстрый старт (Quickstart)

```bash
# Клонирование и настройка окружения (Python 3.12)
git clone <url_репозитория> && cd repo-forecast
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### Режимы запуска

#### 1. Мгновенная проверка заглавных чисел (~0.5 сек)
Валидирует ключевые метрики отчета по закоммиченным витринам `outputs/headline/`:
```bash
make verify
```

#### 2. Запуск тестового сьюта (~12 сек)
Прогоняет 22 бескомпромиссных теста на отсутствие утечек, консистентность данных и точность чисел:
```bash
pytest -v
```

#### 3. Быстрый сквозной контур данных (~10–15 мин)
Загрузка данных, сборка панели и базовая проверка пайплайна:
```bash
make smoke
```

#### 4. Полный цикл воспроизведения бэктеста (~9–11 ч на 8 ядрах CPU)
Полный пересчет всех моделей с нуля:
```bash
make data
make reproduce
```

*Примечание:* В `make reproduce` включен полный бэктест 20 моделей, сетка CPD-детекторов и новостная абляция. Аудит-расширения (`scripts/rc1_*.py`) запускаются поверх сформированного `outputs/` автономно.

## 5. Входные данные и целостность

Сырые данные конкурса в репозиторий не включаются в соответствии с п.9.2.2 Положения. Пайплайн загружает исходные данные по прямым ссылкам и проверяет контрольные суммы SHA-256.

| Источник | Назначение | Лицензия | Контроль |
|---|---|:---:|:---:|
| **Лаборатория СберИндекс** | Панель безналичных расходов 2 016 МО (2023–2024), полигоны GPKG, справочник | CC BY-SA 4.0 | `configs/MANIFEST.sha256` |
| **Банк России (ЦБ РФ)** | Ключевая ставка, ИПЦ, официальный курс USD/RUB (2023–2024) | Открытые данные | Проверка схемы и типов |
| **isdayoff.ru** | Производственный календарь РФ (рабочие/выходные дни) | Открытые данные | Автоматический парсинг |
| **Деловые медиа** | 27 806 заголовков («Коммерсантъ», «Ведомости») | Открытые факты | Фиксация sha256 в манифесте |

Все решения по параметрам и исключениям зафиксированы в `configs/validation.yaml`, `configs/champion.yaml` и реестре решений `configs/decision.json`.

## 7. Методологические ограничения задачи

1. **Глубина панели 24 месяца:** Доступен только один полный годовой цикл в обучении. На горизонте h=12 статистическая мощность обеспечивается пространственной выборкой (2 016 МО), а не временной глубиной.
2. **Экстраполяция форварда на 2025 год:** Прогноз на 2025 год валидируется на национальном агрегате официального ряда СберИндекса (на муниципальном уровне данных за 2025 год нет). Категорийный сдвиг на Общепите (+52.7% г/г) честно разобран и объяснен институциональным обелением сектора.
3. **Физика опережающих сигналов:** На месячной дискретности опережающего сигнала заблаговременного предсказания шоков не существует (доказано экспериментально). Инструмент эффективен для оперативного мониторинга и интерпретации с задержкой 0–1 месяц, опережая релизы Росстата.
