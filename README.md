# Прогнозирование потребления и раннее выявление шоков в муниципалитетах России

Решение задачи направления «Прогнозирование» онлайн-конкурса СберИндекса 2026.

**TL;DR**: (заполняется по итогам прогонов)

## Воспроизведение

```bash
make reproduce   # окружение → данные → панель → все прогоны → отчёт
```

| Число в отчёте | Команда |
|---|---|
| (заполняется) | `make stats` |

## Данные

Используются наборы данных Лаборатории СберИндекс (лицензия CC BY-SA 4.0, атрибуция: Лаборатория СберИндекс, sberindex.ru): потребительские безналичные расходы на уровне муниципальных образований (2023–2024), индекс доступности рынков, автодорожные расстояния, справочник муниципальных образований. Сырые данные в репозиторий не включены; загрузка: `make data` (скачивание с официальных URL + проверка sha256).

## Структура

- `configs/` — замороженные до прогонов конфигурации валидации и выбора модели (pre-registration)
- `src/` — панель, валидация, метрики, модели, детекторы
- `scripts/` — шаги пайплайна
- `reports/` — методологический отчёт и презентация
- `outputs/` — результаты прогонов (не версионируются)
